# Game Design Document — Prototype v0.3

## วิสัยทัศน์

เกมเน้นเรื่องและการตัดสินใจ ความไว้วางใจไม่ได้เกิดจากเลือกคำตอบที่ดูดีครั้งสุดท้าย แต่สะสมจากการเปิดเผยข้อมูล การรับฟัง และการยอมให้ผู้อื่นมีส่วนตัดสินใจ ความรู้กับความสัมพันธ์สร้างทางออกต่างกัน

เป้าหมายระยะยาว: 2.5D narrative RPG, exploration, turn-based battle, timelines/memory. รุ่นนี้พิสูจน์ narrative loop ก่อนตาม Playable First

## Core loop ที่เล่นได้

เริ่มเกม → อ่าน → เลือก → apply effects → branch/condition → อ่านผลระยะยาว → ending → บันทึก/โหลดหรือเริ่มใหม่. ไม่มีการแพ้จาก HP 0 ใน campaign นี้ เพราะยังไม่มี death-return rules

## บทนำ: ระฆังครั้งที่สิบสาม

สุบารุกับเอมิเลียพบความผิดปกติของชื่อถนนและความทรงจำในย่านเมืองหลวง การสืบสวนพาไปหอจดหมายเหตุและเครื่องเก็บสำเนาความทรงจำที่ถูกใช้งานเกินวัตถุประสงค์เดิม ผู้เล่นเลือกระหว่างช่วยเหลือทันที รวบรวมข้อมูล เปิดเผยหลักฐาน และแบ่งความรับผิดชอบ

เรื่องแบ่ง 6 ตอน มี 12 decision points. เส้นทางกลับมารวมกันหลังผลลัพธ์ย่อยเพื่อควบคุม scope ของ solo development แต่ flags/stats ยังคงอยู่และเปลี่ยนฉากต่อไป. ฉากจบมี 4 แบบ ไม่มีคำตอบท้ายเรื่องที่รับประกันผลดีที่สุดโดยไม่สนใจการเล่นก่อนหน้า

ตัวละครหลัก: สุบารุ/เอมิเลีย. ตัวละครต้นแบบใหม่: เนริน (เด็กพยาน), ลิออร่า (ผู้ดูแลเอกสารฝึกหัด), ออร์เวน (ผู้ดูแลหอระฆัง). บทสนทนาแต่งใหม่ทั้งหมดและไม่ใช่เนื้อเรื่อง canon

## สมดุลต้นแบบ

HP เริ่ม 100; ผลเสียรวมในเรื่องไม่ทำให้ตาย. Trust clamp -100..100; เกณฑ์ฉากจบความสัมพันธ์ 20. Knowledge สำหรับ restoration 18 และต้องเผยแพร่เอกสารด้วย. ค่าทั้งหมดเป็น balance ของบทนำ ไม่ใช่ฐานสำหรับ battle system

UI แสดง HP/Trust/Knowledge/Courage เป็นข้อมูลเล่นต้นแบบ แต่ไม่เปิดเผย effects ของปุ่มล่วงหน้า. คู่มือสปอยล์แยกต่างหากสำหรับ QA/ผู้พัฒนา

## ภาพและเสียง

ฉากหลัง SVG สร้างใหม่, portrait silhouette, Theme สีเข้ม, typography ไทย/อังกฤษ. Scene World มี Orthographic Camera แต่ยังไม่แสดง exploration จริง. ไม่มี music/SFX ในรุ่นนี้

## เกณฑ์จบงานชุดนี้

เปิด Main ได้, อ่านไทย/อังกฤษถูก, กดข้าม typewriter ได้, เลือกแล้วผลไม่ซ้ำ, ทุกเส้นทางจบได้, Save ไม่ทำลายสถานะเมื่ออ่านไม่ได้, เพิ่มเรื่องด้วย JSON, มีคู่มือและผลทดสอบจริง. ไม่ใช้เกณฑ์นี้อ้างว่า RPG ทั้งเกมเสร็จ
