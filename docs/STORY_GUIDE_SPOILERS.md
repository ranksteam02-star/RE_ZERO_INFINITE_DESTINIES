## ฉากจบ

1. **เมืองที่เรียกชื่อกันอีกครั้ง** — c12 คืนความทรงจำ, Knowledge >=18 และ distributed_records=true
2. **รุ่งเช้าของผู้ที่ยังอยู่** — c12 ตัดแกน และ Emilia Trust >=20
3. **ผู้เฝ้าประตูเพียงลำพัง** — c12 ตัดแกน และ Emilia Trust <20
4. **รุ่งเช้าที่ยืมมา** — c12 คืนความทรงจำ แต่ความรู้ไม่ถึง 18 หรือไม่ได้แจกทะเบียน

## ผล enumerate

จากชุดตัวเลือก 4,096 รูปแบบ: จบ 1 = 608, จบ 2 = 1,206, จบ 3 = 842, จบ 4 = 1,440. นี่คือจำนวนชุดตัวเลือก ไม่ใช่ความน่าจะเป็นของพฤติกรรมผู้เล่นจริง

ทุกหน้า UI 164 nodes เข้าถึงได้ (152 dialogue +12 choice) และทุกเส้นทางผ่าน dialogue 104 หน้า. Condition 4 nodes resolve ภายในและไม่สร้างหน้าข้อความ

## แนวทางเพิ่มบทต่อ

ใช้ผลจบเป็นข้อมูลตั้งต้นที่มีความหมาย ไม่ย้อนล้างความเสียหายทันที. ก่อนเขียน TimelineManager ต้องกำหนดว่าสิ่งใดเป็นความทรงจำส่วนตัว สิ่งใดเป็นโลก และสิ่งใดคงอยู่ข้ามรอบ. ตอนจบนี้ยังไม่ได้เปลี่ยน timeline ID และไม่ใช่ death loop ที่เล่นได้
