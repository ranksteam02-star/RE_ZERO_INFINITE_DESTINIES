# ทรัพยากรและสิทธิ์

- `assets/backgrounds/dusk.svg`: ภาพเมือง silhouette ที่สร้างใหม่สำหรับ prototype
- `assets/characters/portrait_placeholder.svg`: ภาพบุคคลเชิงสัญลักษณ์ที่สร้างใหม่ ไม่ใช่งานภาพอย่างเป็นทางการ
- `assets/fonts/Sarabun-Regular.ttf`: Sarabun โดย The Sarabun Project Authors, SIL Open Font License 1.1 ตาม `assets/fonts/Sarabun-OFL.txt`; source: https://github.com/google/fonts/tree/main/ofl/sarabun
- เรื่อง “ระฆังครั้งที่สิบสาม”, บทสนทนา และ NPC เนริน/ลิออร่า/ออร์เวน: เนื้อหาแต่งใหม่ในโปรเจกต์นี้
- ชื่อ Re:Zero, Subaru และ Emilia เกี่ยวข้องกับผลงานต้นฉบับและผู้ถือสิทธิ์เดิม โปรเจกต์นี้ไม่อ้างความเป็นเจ้าของหรือความเป็นทางการ
- ไม่มีเพลง เสียงพูด ภาพจากอนิเมะ หรือ asset ที่ดึงจากเกมต้นฉบับ

ยังไม่ได้กำหนด license แจกจ่าย source ทั้งโปรเจกต์ในนาม Owner. การเก็บ repository private ไม่ได้ให้สิทธิ์เผยแพร่เชิงพาณิชย์โดยอัตโนมัติ ให้ประเมินสิทธิ์ก่อนเผยแพร่ตามข้อกำหนดของ Owner
